# Exercises — 01 Platform Architecture

Short, in-class exercises for exploring the cluster you just installed. Do them in order.

**Before you start:** a working cluster (`kubectl get nodes` shows `Ready`). Take a snapshot if you don't have `cluster-ready` yet.

| # | Exercise | Time |
|---|---|---|
| 001 | [Explore the node](001-explore-the-node.md) | 10 min |
| 002 | [Find the control plane](002-find-the-control-plane.md) | 15 min |
| 003 | [kubectl vs crictl](003-kubectl-vs-crictl.md) | 15 min |
| 004 | [Namespaces and API resources](004-namespaces-and-api-resources.md) | 10 min |
| 005 | [Static Pods](005-static-pods.md) | 15 min |
| 006 | [The Pod network](006-pod-network.md) | 15 min |

Each exercise has: a goal, tasks, questions to answer, a hidden solution, and a cleanup step.
Try to answer the questions **before** opening the solution.
